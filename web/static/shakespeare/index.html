About this model

This 10.8M-parameter character-level transformer was trained for 40 epochs on a single T4 using the complete works of Shakespeare. Its validation loss reached 1.87.

The int8 checkpoint is about 11 MB. Generation uses a KV cache and runs in WebAssembly in this browser.
